# Skeptic challenge: Neuro Serpent (W4-S2, recommended Variant A)

## TL;DR
- **BLOCKED:** 0 BLOCKER · 1 HIGH · 7 MED · 4 LOW (12 rows). The renderer holds: depth stays inside the native, the engine does not change, MSAA is A/B'd first and mode S is the fallback. The open HIGH is the rig's drop trigger.
- **S-1 HIGH:** one frame of `presence` > θ·peak fires the whole drop cascade. There is no hysteresis, no minimum on-time and no abort. A bass stab before the drop, or a kick tail that outlives the 0.2 s HOLD, spends `W` before the drop. R5, C13 and C14 then fail, and nothing catches it before S6.
- **Cost (S-7, S-8, S-9):** on ANGLE-Metal, mode M pays an implicit resolve, the blit copy, and stores of the MSAA colour and depth: ≈ 139 MB/frame, with no `invalidateFramebuffer`. The body row leaves out 2×2-quad overshading (≈ ×1.6–2.0, computed). Mode S in a slow session comes to ≈ 3.9–5.3 ms, not ≤ 4.7, and mode M to ≈ 4.3–6.4 ms. L1 (front-to-back sort) saves ≈ 0 on Apple TBDR.
- **Clock (S-4):** the RL L-4 lesson repeats. Windows in seconds run on the native's `f.dt`, which heat and layer speed scale and nothing clamps. **Flash:** the whip cannot read as a full-frame flash. The 5.8 Hz strobe of the ripple dashes has no numeric gate (S-5).

## §2 Checked and holding
- **MSAA on RGBA16F.** Chromium makes float MSAA under EXT_color_buffer_float optional per implementation (codereview 2197893003). engine.ts L22 enables the extension before any renderbuffer exists. The spike's `getInternalformatParameter(RENDERBUFFER, RGBA16F, SAMPLES)` check plus the mode S fallback cover a 0-sample answer. The resolve formats match: RGBA16F ↔ `renderTarget(true)` (engine.ts L81).
- **Depth renderbuffer.** DEPTH_COMPONENT24 is core WebGL2, and it stays inside the native, so the engine does not change. NEAR .05 / FAR 100 with 24-bit depth at ≈ 2.4 world units gives ≈ 7e-6-unit steps (computed), so self-crossings show no z-fighting.
- **GL state.** Grep of `web/src` finds 0 hits for DEPTH_TEST, CULL_FACE, depthMask, renderbufferStorage, blitFramebuffer, colorMask and READ_FRAMEBUFFER, so the native is the first user. The design's "GL state diff = {}" row covers a leak. Add colorMask or blendFuncSeparate to the restore list, because the particles leave alpha untouched.
- **Context loss.** engine.ts L17 reloads the page, so no renderbuffer restore path is needed. The T-LC and T-CTX rows apply as written.
- **The whip as a flash.** The native's only flash-class input is `flare`, gated by `flashGate` on the app clock (live.ts L329, post.ts L46–L58). The whip raises luma ×1.4 over 2 beats (C13), and the sparks and the white-hot band are local (≤ 5 %). The one full-frame step is the app's drop flash (post.ts L12–L13) together with the gated flare. The single exception is S-5.
- **Clipped white under the app flash.** The output is .8 + .2·dst, so a pixel clips only where the scene itself clips. The tone map 1 − e^(−m) needs m ≥ 6.2 to reach code 255 (lasers.ts L544), so C15's ≤ 20 % is a property of the scene.
- **Banding in the fog.** A TPDF ±1 LSB hash dither runs before the RGBA8 write (lasers.ts L545–L546). The RGBA16F step at fog levels .03–.08 is ≈ 3e-5, far below 1/255. The post gain blend scales the dither with the signal, so it adds no bands. C5's numeric bound stays with the test-architect.
- **CPU rig.** Per frame: 192 × 16 floats (12.3 KB) plus ≤ 200 parts × 12 floats (9.6 KB) through `bufferSubData`. That is the lasers pattern (256 × 12 floats, 0 late in 3601 frames, STATE RL S6). The RMF and the arc-length resample stay far below 0.1 ms. The draws are instanced and non-indexed, which avoids ANGLE-Metal's slow path for per-frame index-buffer updates (angleproject thread, 2025-11-03).
- **Reuse claims.** Checked: `BLUR` (lasers.ts L14), the tone map and dither (lasers.ts L543–L546), `orbitVP` (view.ts L17), `createRig` / `laserState()` (lasers.ts L581 / L598), `performance.now()` (lasers.ts L601), `createBloom` +3.3 ms (isobars.ts L497–L498).
- **SG1 timing (lead-ruled).** The gate trips on any transient > 1.5× (bands.ts L76), so snares are gated too, not only kicks. On the beat clock, the release starts on a kick-coincident return at +0.2 s and the late `drop` (+0.3 to +0.7 s) lands on the loop or the crack (design L220).
- **`reeseLevel` contract.** The change is additive. `SOURCE_IDS` is pinned (bind.ts L26), and `sourceGroups` must list the new id once (bind.ts L30–L39). The dubstep Auto-style map remaps only `reese` → `wobble` (presets.ts L44).

## §3 Verdict
**BLOCKED.** Counts: BLOCKER 0 · HIGH 1 (S-1) · MED 7 (S-2 to S-8) · LOW 4 (S-9 to S-12).
- What holds up: Variant A's structure, the M/S A/B order (lead ruling), the fallback logic (B fails R2, C is used only if both modes fail), flash safety of the whip, banding, the CPU rig, the lifecycle on context loss.
- Routing: S-1 → system-designer + creative-director (the stab policy against C12's 3 frames). S-2 and S-3 → system-designer, with audio-dsp running the replay. S-5 → test-architect row + creative-director. The other rows go to the designer's `## Skeptic response`, or to the plan as spike tasks.
- Cheapest single check: the S-1 Node replay on the existing w4sim dumps. It settles S-1, S-2 and S-3 in one run, with no browser.
