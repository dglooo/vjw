# Research — the "TouchDesigner look" and how to rebuild it

## TL;DR
- The "TD look" is mostly **feedback chains of cheap TOPs**, not exotic shaders. The canonical snippet (`feedbackTOP` ex3): the history fades, hue-rotates, gains saturation, zooms 2 %, is displaced by drifting perlin noise, gets edge-traced and blurred, and the source is screened on top. TD's own shaders are few and small (light tunnel, twirl, radial blur, optical flow). Several credit Andrew Benson / v002, the same lineage as donor ISF-Files.
- Of the 13 public looks plus 6 from the dump: kaleido, RGB split and basic feedback are **have**. The feedback-fx / feedbackEdge chains, bloom pyramid, light tunnel, radial blur, optical-flow smear and (⚠️) reaction-diffusion are **easy** in today's ISF engine.
- **Engine gaps:** a frame-history ring (RGBA delay, time machine); a cross-layer texture input (displace by another layer); IMPORTED LUT images; and an instanced/point renderer + particle-state layer (particles, pixel scatter, point clouds; WebGL2 has no compute).
- TD's noise library is Brian Sharpe's public **Wombat** (ashima-derived). The dump has no reaction-diffusion or kaleidoscope shader. TD keeps cost low by running optical flow at 1/8 res and feedback at 512²; there are no public M4 ms numbers (§4).

## §1b TD's own components (dump): chain, math, params, mapping

## §2 Mapping to VeeJay Wizard

## §4 GPU cost vs the 5 ms/scene budget (M4, 1728×1117, scale 1)
Budget: `agents/system-designer/design_effects.md` E2 (≤5 ms GPU p95 per built-in scene). Public sources give **no M4 or WebGL ms numbers** for any of these looks: ⚠️ unknown unless noted.
- **Our own measurements (internal, not public):**
  - A half-float feedback pass costs about 1 ms at 1728×1118 (`agents/planner/plan_effects.md` L448: trails 3.04, feedback-zoom 3.07, echo 2.55 ms median over a tunnel at 1.99).
  - Single-pass ISF filters add ≈0.4–0.9 ms over the tunnel alone (1.34): e.g. Chromatic Aberration 1.83, Posterize 2.06 (L596).
  - Spectrum bars + bloom + composite: 1.1–1.9 ms at 1200×800 (`plan_pilot.md` L356). Native particles (transform feedback): 5.3 ms median (`plan_effects.md` L387).
  - Butterchurn p95 2.58–3.52 ms (STATE HEAD).
- **How TD keeps these cheap (dump, §1b):** optical flow runs at **1/8 resolution** (blur preshrink 3) on mono input; the "feedback fx" snippet runs at **512²**; bloom is a half-res pyramid (5 levels by default); radial blur is one pass with N taps.
- **Public algorithm sizes:**
  - Bloom TOP: 1024² input → 10 blur levels ([Bloom TOP](https://docs.derivative.ca/Bloom_TOP)); `Passes` > 1 multiplies the cost.
  - Gray-Scott (jsexp): 8 steps per frame on float targets at half canvas size (§3).
  - WebGL fluid: 20 Jacobi pressure iterations on a 128² sim grid, 1024² dye, 8 bloom iterations (§3).
- **Memory, computed:**
  - One RGBA8 frame at 1728×1117 = 7.7 MB. A 30-frame history (rgbaDelay) = 232 MB, a 32-frame one (Time Machine snippet) = 247 MB; at half res 58 / 62 MB.
  - RGBA16F doubles these. Design E2 already budgets ≈130 MB for a heavy two-scene fade at 60A.
- ⚠️ estimate (extrapolated from the 1 ms/full-res half-float pass, not measured):
  - Gray-Scott at half res (¼ area) × 8 steps ≈ 2 ms.
  - The "feedback fx" chain in one pass with a ~9-tap blur ≈ 1–1.5 ms.
  - A bloom pyramid ≈ 0.5–1 ms (design E2 estimate).
- Pixel scatter at full res = 1.93 M points per frame: cost ⚠️ unknown.

## §5 Ranked shortlist: visual punch for a DJ set ÷ effort
The ranking the brief asked for. Each line names the engine gap; "none" means one own ISF file in today's engine.
1. **TD "feedback fx" chain** (`SN/TOP/feedbackTOP.tox` ex3): the history fades, hue-rotates, gains saturation, zooms 2 %, is pushed along drifting perlin noise, gets edge-traced and softened, and the source is screened on top. Gap: **none** (one `PERSISTENT FLOAT` pass). Bind zoom/displace weight to bass, hue step to onsets.
2. **feedbackEdge contour rings** (`P/IF/feedbackEdge.tox`): edges of the history are re-fed, gain 1.07, ×1.003 zoom per frame, and glow outward. Gap: **none**.
3. **Bloom pyramid filter** (`P/IF/bloom.tox`: threshold .26, 5 levels, luma→ramp tint). It lifts every other layer. Gap: **none** in principle (ISF `PASSES` with halving `WIDTH`/`HEIGHT`). ⚠️ verify the runtime with ~10 passes.
4. **Light tunnel + radial zoom blur** (`P/IF/lightTunnel.tox`, `radialBlur.tox`): radial streaks, strength punched on kicks. Gap: **none** (single passes; fixed loop bound for GLSL 1.00).
5. **Optical-flow smear** (`Tools/opticalFlow.tox` math = donor `ISF/Optical Flow Generator.fs`): flow at 1/8 res displaces a feedback buffer, so motion leaves streaks. Gap: **none** for an own merged file (flow pass + displace-feedback pass; no `.vs`, no second input).
6. **Reaction-diffusion** (public: lygia `grayscott`, jsexp; not in the dump): organic coral that the bass can seed. Gap: **none** if the runtime runs N alternating persistent passes per frame (⚠️ unverified); else a native generator.
7. **RGBA delay / time machine** (`P/IF/rgbaDelay.tox`, `SN/TOP/timemachineTOP.tox`): RGB time-split and per-pixel time warp. Gap: **frame-history ring** (`TEXTURE_2D_ARRAY` of 30–32 frames, ≈60–250 MB) + a GLSL 3.00 sampler path.
8. **GPU particles driven by noise / flow** (`Tools/particlesGpu.tox`, Particle POP + Trail POP): Gap: a **particle-state layer** (TF or float ping-pong; no compute) + an **instanced/point renderer** usable as a layer generator. The same renderer unlocks pixel scatter (`pixelRelocator`) and point clouds.
