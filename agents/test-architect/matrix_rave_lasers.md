## §1 Strategy
- **Layers.** unit = Vitest pure rig (`web/src/scenes/lasers.test.ts`; scripted RigIn at 60 fps, 174 BPM, conf 1, drums armed unless the row says otherwise). contract = instance buffer, bind config, registry, `tone()` constants. browser = headless Chrome harness on Vite at `<lane-port>` (the port in the lead's brief; never 5173), restarted before each run. performance = GPU bench in one session next to the wireform reference, and the 60 s autopilot runs. visual = pixel measure on the stills (1200-px copies, or full-res where the row says so). manual = user review, and the tester's AV judgment.
- **Commands.** Unit commands run from `web/`. Harness commands run from the repo root.
- **Fixtures.** Gates use `scratchpad/fx_audio/dnb174-arr.wav` and `dubstep140-arr.wav` (mono; Chrome reads [x, 0]). Stereo: `scratchpad/ed/dnb174-arr-stereo.wav` (G-AUTO only). Real tracks in `tracks/` (lead-local, never committed): Kanine, Sub Focus, Andy C, used for stills and full-length flash only. Silence: none. T-C11s is synthetic (zero features, no file).
- **Clock and seed.** Unit tests: `RigIn.time` = frame ÷ 60, never `performance.now()`. No random source. The dither hash keys on the frame index.
- **Resolution.** 1728×1117 CSS px at deviceScaleFactor 2, app flash ON (creative §7).
- **Owner** = who acts on a FAIL. frontend-coder: code, rig, bench levers. lead: gates, harness runs, real-track runs, routing. tester: AV QA verdicts (T-F3m). user: stills. A normal-class bench session gives a projection, never PASS.
- **Harnesses** (directory `scratchpad/ed/rave-lasers/`; the coder names the spike copy it starts from): `rl-bench.mjs` (modes `bench`, `run`, `flat`; base `w3s21-laser.mjs`; `run` replaces the former `rl-run.mjs`), `rl-stills.mjs` + `rl-gap.py` (metrics) + `rl-sheet.mjs` (spike copies, extended in S5.4), `rl-60s.mjs` (new; base `cp4-60s.mjs`), `rl-lifecycle.mjs` (new; T-L11, T-LC, T-SH: T-SH runs inside it), `rl-ctx.mjs` (new). Not created: `rl-run.mjs`, `rl-compile.mjs`.
- **Argument order (⚠️ Assumption, needs confirmation):** the commands read `rl-bench.mjs <mode> <fixture> <port>` and `rl-60s.mjs <fixture> <port> <seconds> <layout> [auto]`, as the S5.2/S5.3 file headers state. The coder's header is authoritative; if it differs, the commands change, not the test.
- **Visual rows:** capture with `rl-stills.mjs <kanine|andyc|subfocus> <port> <tag>` (S5.4 usage), then measure with `rl-gap.py metrics <tag>` (S5.4 usage). Tile → track: S1, S6 Kanine · S2, S7, S8 Andy C · S3, S4, S5 Sub Focus. The coder's headers stay authoritative (⚠️ Assumption on the full-res flag).
- **Phases:** each row's `phase` is the plan step that owns it (plan `## Steps`). Spike rows keep S3.
- **Not applicable:** frozen pair (no existing native gains an input). Kick/snare/hat discrimination is upstream in the existing `web/src/audio/drums.test.ts` and `onset.test.ts` (unchanged); T-C12 checks it end to end.
