## §1 Strategy
- **Layers:** unit (Vitest on pure seams: `cd web && npm test -- <file>`); contract (grep, git, du); browser (main app `?debug` or `?camprobe`, Playwright, headless); performance (60 s runs, billed A/B, GPU bench); manual (user stills, live camera).
- **Harness:** `scratchpad/cam/probe.mjs` gains a `fake` source (its camera branch throws at L139–L140; the page already takes `__camprobe.select(deviceId)`) and a probe-only `&fault=` field (S1.2b). `scratchpad/cam/cam-app.mjs` (new, S1.3) drives the main app with `?debug`, headless, fake device; the B-entries name their case as the argument. Until S1.3 only `probe.mjs` exists.
- **Real camera:** no test calls `getUserMedia` without `--use-fake-device-for-media-stream` (Chrome then replaces every video device). `enumerateDevices` does not open the camera and is allowed. The real device is the user's (M2, M3, M5, M6).
- **Stubs:** `getUserMedia` rejections and controlled resolve order come from `page.addInitScript` (no fixture file).
- **Clock and seed:** the watchdog and the retry take an injected `now` (no wall clock in Vitest). Browser windows use the `minWindowFps` rule (`metrics.ts`). Synthetic fixtures use fixed ffmpeg arguments (no randomness).
- **Headless vs GPU bench:** U-, C- and B-entries headless. P1 (`mainMs`), P2 and P6 headless. P3–P5, P7, P8 (`camGpuMs`, 1728×1117 late runs, billed timer) are GPU bench: the lead announces the visible window first.
- **Not applicable (SDLC §3 Stage 2):** silence, drum discrimination beyond the camera binds, double hits, tempo change, break/drop, audio→visual latency. B21 and B22 cover the audio side of the camera binds.
- **Stays manual:** spec §4.2 stills, K4 by eye, the K-2 live arm, the S3/S7 stills gate for `dj-*`, the PC run, the Windows privacy text, the CP3 live walk.
