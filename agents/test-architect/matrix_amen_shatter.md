## §1 Strategy
- **Layers.** unit = Vitest pure core, `web/src/scenes/shatter.test.ts` (proposed path; each test name starts with its ID, so `-t <ID>` filters). Synthetic streams: `now` = `audioNow` = frame ÷ 60 s, seeded PRNG only. contract = `tsc` and the builtin registry. browser = headless Chrome on the lane port (never 5173). Bases: `w3s21-laser.mjs` (per-param r via `window.__src`, `__flash`), `cp4-60s.mjs` (late frame = rAF > 1.5× phase median), `mosaic-bench.mjs` (gpuMs med/p95). `compile-check.mjs` hard-codes own/julia: the copy targets the Shatter shader. Harness dir `scratchpad/ed/amen-shatter/` (proposed; the coder's header is authoritative).
- **Fixtures.** `scratchpad/fx_audio/dnb174-arr.wav`, `dubstep140-arr.wav` (mono; Chrome reads [x, 0]). Real tracks in `tracks/` (Kanine, Sub Focus, Andy C; lead-local, never committed): stills, T-C5a, T-R5h, T-R3p.
- **Run types (E6).** Held run: LOCK on, `locked` for ≥ 8 bars before T0. Cut-in run: fresh scene at T0.
- **Seeds.** The S3 seed (planner fixes the value) and a second seed whose disc centre x lies in (.425, .575), for T-C12t.
- **Guards.** Pixel numeric rows (T-A9, T-C2p, T-C3p, T-C13p) are measure-only until the user's look OK, then regression guards. Hard gates: T-R2a/b, T-R3f, T-R3l, T-R3p, T-C12t.
- **Bench class.** A non-normal-class session gives a projection, never PASS (RL rule). Each bench row logs its session class.
- **Not applicable.** Frozen pair (no existing native gains an input). Stereo (design reads shared features only, ⚠️ not verified; if an L/R feature is added, use `scratchpad/ed/dnb174-arr-stereo.wav`).
- **Owners.** frontend-coder: tests and harness copies. lead: gates, harness runs, routing. user: stills (T-M1, T-M2 eye with creative-qa).
